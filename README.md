
# 🛠️ kotlinify

Kotlin-inspired utility traits for Rust, bringing convenient functions like `coerce_in`, `take_if`, `also` and `apply` to Rust.

## Installation

```bash
cargo add kotlinify
```

## Documentation

See the full documentation, examples and available traits on [docs.rs](https://docs.rs/crate/kotlinify/latest).
